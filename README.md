# 🤖 JEE Study Assistant

AI-powered study assistant for JEE Main, JEE Advanced, and Board students.

Built using Python, Groq API, and Llama 3.

## Features

- Concept Explanation Mode
- Formula Revision Mode
- MCQ Practice Mode
- Quick Revision Mode
- Real-Life Examples
- Hinglish Explanations
- Automatic Notes Saving
- Error Handling

## Tech Stack

- Python
- Groq API
- Llama 3 (llama3-8b-8192)
- Python Dotenv

## Installation

1. Clone the repository

2. Install dependencies

pip install -r requirements.txt

3. Create a .env file

GROQ_API_KEY=your_api_key_here

4. Run the project

python study_assistant.py
