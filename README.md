🤖 JEE Study Assistant
An AI-powered study assistant for JEE Main, JEE Advanced, and Board students.
Built using Python, Groq API, and Llama 3 to provide instant concept explanations, formula revision, MCQ practice, and quick study notes in simple Hinglish.
✨ Features
✅ Concept Explanation Mode
✅ Formula Revision Mode
✅ MCQ Practice Mode
✅ Quick Revision Sheets
✅ Real-Life Examples
✅ JEE-Oriented Explanations
✅ Hinglish Learning Support
✅ Automatic Notes Saving
✅ Error Handling
🛠 Tech Stack
Python
Groq API
Llama 3 (llama3-8b-8192)
Python Dotenv

🚀 Installation
Clone the repository:
Bash
git clone https://github.com/your-username/JEE-Study-Assistant.git
Move into the project folder:
Bash
cd JEE-Study-Assistant
Install dependencies:
Bash
pip install -r requirements.txt
Create a .env file:
Environment
GROQ_API_KEY=your_api_key_here
Run the application:
Bash
python study_assistant.py
