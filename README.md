# JEE Study Assistant 🤖📚

AI-powered study assistant for JEE & Board students built with Google Gemini API.

## Features
- Concepts explained in simple Hinglish
- Real-life examples for better understanding  
- Practice questions with answers
- Supports Physics, Chemistry, Maths

## Tech Stack
- Python
- Google Gemini API (gemini-2.0-flash)
- Google Colab

## How to Use
1. Clone this repo
2. Install: pip install google-genai
3. Add your Gemini API key
4. Run study_assistant.py
